# 数据重叠与论文报告协议

本说明依据本次本地全量文件审计，汇总见 [initial_data_audit.md](initial_data_audit.md)。所有图像及掩码均完整解码，掩码逐像素检查；原始数据没有删除、移动或修改。以下“无重叠”仅指文件名规范化 ID 和完整解码 RGB 精确哈希检查，不等于患者级独立或已经排除近重复。完整JSON清单由audit命令生成，不纳入Git。

## 训练和验证

默认保留源域训练集，从源域验证集排除与训练集同 ID 或同解码 RGB 的样本，并记录排除名单。这样保留训练样本数量，避免使用已见图像选择 checkpoint 或超参数。此策略不改变磁盘文件，只改变数据加载清单。若用户要求严格检查，可将重叠策略设为报错；不应静默保留重叠。

| 源域 | 原始训练 | 原始验证 | 验证排除 | 实际验证 |
|---|---:|---:|---:|---:|
| ISIC2017 | 2000 | 150 | 1 | 149 |
| ISIC2018 | 2594 | 100 | 0 | 100 |

ISIC2017 的 `train/ISIC_0012970.jpg` 与 `val/ISIC_0012127.jpg` RGB 像素相同，因此默认排除后者。排除验证图像不会消除训练集中对该图像的接触；审计测试重叠时仍需使用训练和选模数据的并集。

## 测试必须同时标明完整集和剔重子集

完整测试集保留供既有文献口径参考，并明确标记已发现的重复污染；与源训练/验证精确重叠的图像从派生测试子集中排除。两个结果分别命名，不应把剔重子集成绩写成官方完整集成绩，也不能把含训练重复的完整集成绩描述为独立泛化证据。

| 模型训练/选模来源 | 测试目标 | 完整测试 | 与已见数据重叠 | 无精确重叠子集 |
|---|---|---:|---:|---:|
| ISIC2017 | ISIC2017 | 600 | 3 | 597 |
| ISIC2017 | ISIC2018 | 1000 | 0 | 1000 |
| ISIC2017 | PH2 | 200 | 0 | 200 |
| ISIC2018 | ISIC2018 | 1000 | 0 | 1000 |
| ISIC2018 | ISIC2017 | 600 | 532 | 68 |
| ISIC2018 | PH2 | 200 | 0 | 200 |

特别注意 ISIC2018 到 ISIC2017 的方向：600 张测试图像中有 529 张同 ID 重叠，另有 3 张不同 ID 但同 RGB，最终只剩 68 张。完整 600 张不适合用来支持独立跨域泛化结论。68 张样本较少，结果不宜与另一方向的 1000 张简单平均成一个“跨域分数”；应报告样本数、每图指标分布及不确定区间。

ISIC2017 的 597 张无训练/验证重叠样本内部仍含两组相同 RGB，因此共有 595 个唯一 RGB。当前剔重协议只去除与已见数据的重叠，不自动合并测试集内部重复；如果进一步合并，应另设协议并报告数量，且预先定义重复图像存在不同掩码时的处理规则，不能按模型结果挑选标注。

**PH2 的 200 张全部为外部测试。** 不用 PH2 选择 epoch、阈值、数据增强、模型宽度或候选机制。各方案的 checkpoint、阈值和超参数必须由源域训练/验证确定后再评估。

## 推荐论文中的表述

可按实际运行设置填写：

> 我们使用预先给定的数据划分，并以规范化图像标识及解码 RGB 像素哈希检查精确重复。训练图像保持不变，验证集中与训练集重复的样本被排除。对于存在训练/验证重叠的测试集，我们分别报告完整测试集与排除重叠后的派生子集结果，并明确标记样本数量。所有模型使用相同的数据清单、验证选择规则和测试阈值。PH2 仅作外部测试。由于缺乏患者/病灶元数据，该审计不保证患者级独立，也不能排除经过不同压缩、缩放或拍摄形成的近重复。

同一实验表至少保留：训练来源、验证数量、目标数据集、协议名（full / exact-overlap-excluded）、测试数量、重叠数量。不同模型在同一张表比较时必须使用相同协议与相同样本 ID 清单；不得用某模型的完整集分数比较另一模型的剔重子集分数。

若报告置信区间，可在固定测试清单上做配对重采样；ISIC2017 内部重复应按 RGB 组采样，避免把精确重复当作独立样本。多随机种子的变化和测试图像采样区间含义不同，分别说明。

## 标注和完整性备注

6644 对图像/掩码全部为 256×256，一一配对，无解码错误、尺寸不一致、孤立文件或空掩码，掩码原始值为 0/255。ISIC2018 test 的 `ISIC_0023056_segmentation.png` 为全前景，需结合图像解释；全前景本身不是自动删样本的理由。

1066 组相同 RGB 图像在不同记录中对应非完全相同的二值掩码，包含跨年份标注差异。这只说明标注版本不同，不能直接判断哪一版错误；同时，标注不同不会使已见图像变成独立测试数据。
