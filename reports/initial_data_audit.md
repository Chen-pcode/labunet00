## 文件与掩码完整性

缺失目录：0；解码错误：0；图像掩码尺寸不一致：0；缺失掩码：0；孤立掩码：0；非0/1或0/255二值掩码：0；全前景掩码：1；相同RGB对应不同二值掩码组：1066。

唯一全前景掩码：`isic2018/test/masks/ISIC_0023056_segmentation.png`。全前景不自动等于标注错误，应结合原图检查。所有划分均没有空掩码。

ISIC2017 test 内另有两组不同 ID 的相同 RGB：`ISIC_0012152 / ISIC_0015979`、`ISIC_0012216 / ISIC_0016001`。597 张不与本年 train/val 重叠的测试样本仍含这些重复，实际有 595 个唯一 RGB；是否进一步合并属于单独评测协议，原始数据未改。

使用 ISIC2018 train/val 后，ISIC2017 test 的 532 张剔除包括 529 张同 ID/同 RGB 和 3 张仅 RGB 命中：`isic_0016001`, `isic_0016002`, `isic_0016018`。余下 68 张也是 68 个唯一 RGB。

1066 组相同 RGB 对应非完全相同的二值掩码，包含跨年份标注差异；这里只确认掩码不相同，不能由此断言标注错误，也不能把图像重叠忽略掉。

**PH2 共 200 张，全部是测试数据。** 当前没有 PH2 训练/验证划分；若将其用于外部测试，不应在其上选超参数或模型。

ISIC2017 与 ISIC2018 存在数据重用，因此不能把所有跨年份测试直接解释为独立域泛化。尤其使用 ISIC2018 train/val 后，评估 ISIC2017 完整 test 会包含已见图像。剔重结果应单独报告，不能冒充官方完整测试结果。

本审计不能识别不同压缩/缩放后的近重复、重复就诊或患者关系；没有病例元数据，尚未做患者级泄漏审计。完整本地清单不纳入Git；运行 `python -m skinmamba audit --data-root ../data` 可重新生成各来源的排除 ID 及详细结果。
